# OPSFORGE AI Build Lab

A public-facing Streamlit portfolio hub connecting Sangram Ghatge's independent AI/MarTech prototypes to enterprise problems, evaluation criteria and current research.

## Run locally

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Sign in at https://share.streamlit.io/
2. Select repository `sghatge/sghatge`, branch `main`.
3. Set main file path to `build-lab/app.py`.
4. Deploy.

## Included

- Curated build catalogue with repository and demo links.
- Research radar connecting recent AI research to relevant prototypes.
- Transparent, user-entered prototype evaluation rubric with CSV export.
- LinkedIn post studio with editable copy and downloadable draft.

## Important boundaries

- This hub is a portfolio index and evaluation aid, not a production certification.
- Project stages are labelled; a repository link does not imply a hosted interactive demo.
- Research notes are short summaries. Read the original papers for methods, caveats and full findings.
- Never enter confidential, customer, employer or production data.
- Prototype scores are user-entered and not independently validated.
